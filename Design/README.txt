AQUA AIR — HTML DESIGN PREVIEW

CÁCH MỞ
1. Giải nén toàn bộ gói này.
2. Mở index.html bằng Chrome, Safari hoặc Edge. Không cần cài đặt hoặc Internet.
3. Chọn một trong 12 màn hình ở danh sách bên trái; trên điện thoại danh sách cuộn ngang ở phía trên.
4. Thư mục screens có 12 file HTML riêng, mỗi file mở trực tiếp được và có giao diện vừa màn hình điện thoại.

CÓ THỂ BẤM THỬ
- Tổng quan, xem bể, tìm kiếm và lọc.
- Thêm bể, chọn ảnh, tạo lịch đầu tiên.
- Ghi nhận thay nước, nhập tỷ lệ, chọn ngày, ghi chú và ngày tiếp theo.
- Xem/sửa/xóa hoạt động, tính lại hạn.
- Chỉnh chu kỳ, tạm dừng, nhắc trước, giờ nhắc và hoãn nhắc.
- Xuất/khôi phục file JSON cho dữ liệu demo.
- Lưu trữ và mở lại bể, khôi phục dữ liệu mẫu.

LƯU Ý
Đây là HTML prototype minh họa thiết kế cho dự án React Native, không phải app native hoàn chỉnh. Dữ liệu mẫu dùng ngày 28/10/2026 để các trạng thái overdue/upcoming hiển thị ổn định. Notification được mô phỏng trong trang, không gửi nhắc trên điện thoại. Dữ liệu demo được lưu bằng localStorage khi trình duyệt cho phép; các trình duyệt có thể tách dữ liệu giữa từng file HTML mở bằng file://. Vì vậy nên dùng index.html để thử luồng đầy đủ. Mỗi file trong screens vẫn có thể mở riêng để xem thiết kế. Ảnh mẫu được nhúng sẵn. File đặc tả là nguồn chuẩn cho hành vi của bản React Native; demo dùng JSON export đơn giản, không thay thế thiết kế backup .aquaair của sản phẩm.

Bản này là giao diện HTML/CSS dựng lại để bấm thử; không phải ảnh PNG được cắt từ mockup hay file Figma. Có đính kèm đặc tả đầy đủ để dùng với LLM coding.
